# 自托管账号与同步服务

`service/server.mjs` 提供同源应用、注册登录和学习记录同步。它是可选的自托管账号服务，与默认的 AppDeploy 托管平台账号彼此独立，用户、密码、令牌和记录都不互通。本机 `server.js` 数据也不会自动并入任一云端账号。

## 本机运行

需要 Node.js 24 或更高版本。在项目根目录运行：

```powershell
node service/server.mjs
```

默认地址为 <http://127.0.0.1:8322>。服务数据目录默认是 `service/data/`，包含私有账号数据和密钥，禁止提交或放入公开源码 ZIP。可用 `SERVICE_DATA_DIR` 指定私有目录。

## 公网自托管

跨网络使用时需将服务放在 HTTPS 反向代理之后，并为客户端统一配置自托管 HTTPS 地址。Android、Web 设置和 Windows 入口必须使用同一个地址，才会访问同一套自托管账号。此地址不能与 AppDeploy 托管账号互换。

部署完成后，按以下范围验证：

1. 检查 `/api/health` 返回正常。
2. 在两个独立客户端注册或登录同一个自托管测试账号。
3. 修改学习记录并确认另一客户端收到服务端回执后的状态。
4. 检查版本冲突、退出和本机数据选择路径。

本项目当前未完成真实公网跨网络和真实账号验证。配置文件、脚本或本机测试通过不等于公网发布完成。

## 本机自动化检查

```powershell
node tests/sync-service.mjs
node tests/e2e-sync.mjs
```

根目录 `npm test` 自动运行 12 个测试文件；独立 E2E sync 为 12 步，mocks 为 5 步。各项测试验证范围以测试输出和测试代码为准，不替代真实公网或真机检查。
