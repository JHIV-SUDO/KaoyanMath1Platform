# AppDeploy Cloud 部署说明

当前默认线上入口为 <https://app-2uzt75.v2.appdeploy.ai/>。`cloud/` 保存 AppDeploy 所需的部署源文件和打包说明；代码或源文件更新不代表线上部署已经更新。

2026-10-29 尝试部署本轮前端与后端时，平台返回用量上限；最终更新未上线。18 个 PDF 包及内容分片已上传，仍需平台额度恢复后提交最新入口、后端和测试，再做真实账号验证。

准备部署前运行 `node cloud/prepare.mjs`。既有线上应用应先读取其当前源快照，再根据差异更新；生成文件中的模板 diff 用于新建应用，不应直接覆盖线上既有代码。PDF 包以平台资源上传方式绑定，学习数据和令牌不得包含在部署源码中。

本轮后端以 gzip 分片和事务回执存储状态：原始 JSON 最大 4 MiB，同时受压缩后事务输入上限约 900 KiB 约束；历史内联或未压缩分片格式可读取。体积超限时保留草稿并提示导出。

## 内容范围

平台包含 32 讲、171 道随堂练习、2,186 条题库记录（含重复变式）、833 条仓库笔记、2 套模拟卷和 464 实体/431 关系的知识图谱。基础30讲 350 道例题中有 18 道结构化条目、332 道原书页材料，配套 776 张扫描图片和 18 个内置 PDF 包；53 个锚点待复核。原书页材料是来源资料，不应称为全部完成的高质量精讲。

## 发布检查

部署前确认 Cloud 构建输入包含最新应用数据、PDF 包、图片和资源索引；部署后从公开入口检查应用启动、内部 PDF 按题号定位、核心题库和账号功能。线上真实跨网络及真实账号端到端尚未验证。不得仅凭本地构建或静态检查宣称部署成功。

AppDeploy 托管账号与 `service/server.mjs` 自托管账号是不同账户系统和数据存储，不互通。本机数据不会自动同步到托管账号。Android 默认进入托管平台，可切换本机模式。

源码 ZIP 包含所需的原书 PDF 切片及图片，Android 包亦内置这些资源。GitHub 发布时先解压源码 ZIP 并提交项目文件；ZIP 超过 100 MB 时可作为 Release 附件。代码许可与书籍、扫描页、题目材料的授权分别处理，详见根目录 `THIRD_PARTY_NOTICES.md`。
