# Android 使用与构建

## 使用

Android 应用内置 32 讲、171 道随堂练习、2,186 条题库记录（含重复变式）、833 条笔记、2 套模拟卷，以及 464 个实体和 431 条关系的知识图谱。原书例题材料包括 18 道结构化内容、332 道原书页材料、776 张扫描图片及 18 个 PDF 包；53 个书页锚点待复核。原书页材料不代表高质量精讲或数学内容已经全部验证。

默认启动线上 AppDeploy 平台，可在应用中切换至本机模式。2026-10-29 本轮线上更新因平台用量上限被拒绝，线上仍是旧版；点击顶部“本机”可使用本轮新集成资料。本机资料阅读器支持内置 PDF，无需导入。

托管账号与自托管服务账号彼此独立。本机数据不会自动并入托管账号，迁移时先导出 JSON 并保留原始备份，再在目标模式中导入。自托管服务部署说明见 [service/README.md](../service/README.md)。

## 构建

环境要求：Node.js 24 或更高版本、JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0。PowerShell 7 下运行：

```powershell
& 'D:\ClaudeWorkspace\Projects\KaoyanMath1Platform\android\build.ps1'
```

构建产物需检查包内资源、安装、签名和应用启动；本说明不代表最新 APK 已构建或发布。个人签名密钥应保存在本机私有目录，禁止放入源码 ZIP 或 GitHub。
